# Experiment & Review Artifacts

This directory stores lightweight serialized outputs, benchmark tables, confusion matrices, or visualization samples generated during experiments and quality audits.

---

## Storage Policy
- **Included**: JSON summaries, lightweight HTML review sheets, small sample comparison crops, confusion matrices.
- **Excluded**: Full-size extracted video frames, gigabyte-scale datasets, neural network weights (these belong in `work/`, `output/`, or `models/` and are tracked by `.gitignore`).
